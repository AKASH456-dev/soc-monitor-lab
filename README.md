# SOC Monitor Lab - Wazuh SIEM

## Project Overview
A home lab project for monitoring security events using Wazuh SIEM.

## Lab Environment
- Wazuh Server: Ubuntu 22.04
- SIEM: Wazuh
- Agent: Kali Linux
- Agent Name: kali-agent
